# 复刻包输出模板（Replication Output Template）

用于把拆解报告的「爆款DNA + 底层公式 + 复刻边界」转成可执行复刻包。分**通用段**和**资讯/图文TTS段**。

## 通用段（口播/演示/评测类适用）

```markdown
【新选题定位】
- 新主题：<换掉原主题，保留机制>
- 目标人群：<同原或更窄>
- 核心痛点：<保留原痛点类型>
- 核心承诺：<保留原承诺类型>
- 证据来源：<你的素材，可核实的>
- 建议时长：<参考原时长>

【标题候选】（5 个，公式：情绪词+事件/结果+人群）
1. ...
2. ...
3. ...

【封面/首帧文案】
- 主标题：
- 副标题：
- 画面建议：

【前 3 秒开头备选】
1. 痛点直击：<可直接念的一句>
2. 反常识：<颠覆认知一句>
3. 结果前置：<先给结论一句>

【完整旁白稿】
- 写成可直接念的短句；口语化；每句一个信息点。
- 每 8-12 秒一个留存转折（新信息/案例/演示）。
- 结尾明确 CTA（收藏/评论关键词/关注）。

【新视频分镜】
| 镜号 | 时间 | 画面 | 旁白/字幕 | 动效/素材 |
|---|---|---|---|---|
| 01 | 0-3s |  |  |  |

【字幕花字方案】
- 关键词高亮：...
- 大字卡点：...
- 屏幕贴片/截图：...
- 结尾 CTA 字幕：...

【素材清单】
- 必拍/必做：...
- 可用截图/录屏：...
- 可补充证明：...
- 不建议使用：<来自复刻边界的规避项>

【剪辑提示】
- 节奏：...
- BGM/音效：...
- 镜头/放大：...
- 留存节点：...

【评论/收藏触发】
- 评论问题：...
- 收藏理由：...
- 私信/关注触发：...

【发布前检查】
- 事实核验：...
- 版权/素材：...
- 平台敏感点：...
- 与原视频差异：<对照复刻边界逐条打勾>
```

## 资讯/图文TTS段（幻灯片+TTS 形态专用）

```markdown
【幻灯片脚本】（每页一句话一屏，3-7 秒/页）
| 页 | 画面大字 | 对应 TTS 旁白 | 示意/配图 |
|---|---|---|---|
| 1 | 钩子提问 |  |  |
| 2 | 痛点具象 |  |  |
| ... |  |  |  |

【TTS 配音要求】
- 音色/语速：<男/女、播音腔、字/秒>
- 停顿点：<在关键信息前停顿>

【信息来源清单】（资讯铁律：必须有解读增量 + 可溯源）
- 一手来源：<GitHub 仓库/spec/官方发布，逐条可点开>
- 增量点：<比已有内容多给了什么：细节/规范名/结论>

【信任构建】（可选层）
- 背书：<引用团队/维护者>
- 开放姿态 / 反固化 / 坦陈代价：按需加 1-2 层

【封面】
- 白底大字 + 钩子提问（参考原视频风格，但换配色/排版）
```

## 复刻边界自检清单（交付前必过）

- [ ] 标题/旁白与原视频无重复句式（只保留公式，不保留具体词）
- [ ] 画面/示意图重做（不截原视频）
- [ ] 人设/声音/水印不沿用原作者
- [ ] 故事/数据/截图均改为自己的、可核实的
- [ ] 底层机制保留（人群/痛点/结构/信任/转化）
