# 爆款视频复刻

**输入**：一份爆款拆解报告（来自 `viral-video-breakdown`，含爆款DNA、底层公式、复刻边界）。
**输出**：可直接进生产线的复刻包（标题候选/封面文案/前3秒钩子/完整旁白稿/分镜/素材清单/剪辑提示/评论收藏触发/发布前检查）。

## 运行原则

1. **学机制不抄表达**：只迁移「选题角度/钩子类型/结构骨架/信任构建/转化设计」，必须替换「逐字稿/画面/人设/具体故事/素材」。
2. **可执行优先**：每条输出都能被 1 人直接做出来（可念的旁白、可拍的画面、可找的素材）。
3. **遵守复刻边界**：拆解报告的「不能直接抄的」清单是硬约束，逐条规避。
4. **资讯形态专用**：若复刻对象是图文TTS资讯视频，走 `references/replicate-output-template.md` 的资讯段（幻灯片脚本+TTS旁白+示意图）。

## 工作流

> 颜色标记：🔵 纯脚本/规则｜🟡 LLM 生成｜🔴 决策。

1. **🔵 读拆解报告**：定位「爆款DNA」「底层公式」「复刻边界」「是否值得复刻」。
   - 若报告数据门为 ❌ 或「不值得复刻」→ 提示用户：此样本未过验证，复刻风险高，建议换样本。
2. **🟡 换选题**：保留原机制的「人群/痛点/承诺/结构」，替换为用户的 DSH 新选题（信息增量优先）。
3. **🟡 生成复刻包**：读 `references/replicate-output-template.md`，逐项产出。
4. **🔵 复刻边界自检**：对照「不能直接抄的」清单，检查标题/旁白/画面是否与原视频差异化（逐条打勾）。
5. **🟡 对接生产链**：旁白稿 → 走现有 `writer`/`humanizer-zh` 去AI味；封面文案 → 走 `cover_skill`；分镜素材 → 整理清单。

## 失败处理

- 无拆解报告 → 提示先拆解，不硬复刻。
- 数据门未过 → 提示风险，由用户决定。
- 素材不可得（仓库/截图拿不到）→ 标注「需补素材」，不编造。
