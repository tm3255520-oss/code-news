# 验证层（L4 数据门）——防伪爆款

**为什么必须有这一层**：很多视频"看着像爆款结构"，实际从未被市场验证。本 Skill 的拆解报告**必须先过数据门**，才能输出"值得复刻"。没过的，一律标「未验证爆款 / 待数据」。

## 数据采集（🔵）

数据来源：平台页面元数据（如头条 m.toutiao.com 的 articleInfo）、`web_scraper_mcp`、项目已有采集脚本（`collect_xhs_recent_metrics.py` 等）、或用户提供截图。

需要字段：播放量、点赞、评论、转发/收藏、发布时间、发布到现在的小时数、作者粉丝数、作者视频总数、是否进推荐/热点（bizTag、hot 标记）。

## 判定规则（硬阈值，先粗后细）

### 第一步：绝对量初筛
| 平台 | 播放阈值参考 | 说明 |
|---|---|---|
| 头条/中视频 | ≥ 5 万 | 资讯号中视频爆款量级 |
| 抖音 | ≥ 50 万 | 算法推荐池 |
| 小红书 | ≥ 1 万 | 互动导向 |
| B站 | ≥ 10 万 | 中长视频 |

> 阈值是**参考基线**，随赛道/账号体量浮动。判定必须结合第二步相对基线，不能只看绝对值。

### 第二步：相对基线（必做）
- 作者基线：该账号**历史视频播放中位数**（粉丝 <2 万的小号 vs 百万大号，基线差异巨大）。
- 相对倍数：`本条播放 ÷ 作者中位数`。≥5 倍 → 显著高于常态；0.5-5 倍 → 常态；<0.5 倍 → 低于常态。
- 若作者中位数未知 → 数据不足，标"待数据"，不硬判。

### 第三步：起量趋势（可选）
- 发布 ≤48h：看**增速**（播放/小时）而非绝对值。今日发布 78 播放但 20 播放/小时 → 可能刚起步，标"观察中"。
- 发布 >7 天仍低播放 → 基本定型，判定为「未爆」。

### 第四步：互动质量
- 点赞率（赞/播放）、评论率、收藏率（收藏/播放）是否异常好/差。
- 高播放低互动 = 泛流量；中播放高互动 = 垂类精准（对复刻反而有价值）。

## 输出格式

```markdown
【数据门】
- 播放 / 点赞 / 评论 / 收藏：…
- 发布至分析：X 小时
- 作者基线中位数：未知 / ≈N（依据：…）
- 相对倍数：…
- 起量趋势：…
- 结论：✅ 通过（已爆） / ⚠️ 观察中（刚发布） / ❌ 未通过（未爆） / ❓ 数据不足
```

## 与「值得复刻」的联动规则

| 数据门结论 | 是否值得复刻 |
|---|---|
| ✅ 通过 | 可进入复刻候选（仍需看复刻边界/账号契合） |
| ⚠️ 观察中 | 标"待复验"，不推荐立即复刻 |
| ❌ 未通过 | 禁止推荐复刻；但可作**反面教材**（拆"为什么没爆"） |
| ❓ 数据不足 | 标"待数据"，不硬判 |

> 反面教材也很有价值：拆"为什么扑街"能反向提炼避免踩的坑，同样进报告。

## 铁律

- 数据门是**硬门槛**，不允许用"我觉得会爆"绕过。
- 数据来源必须可写进报告（平台名+字段），不编造数字。
- 作者中位数未知时，禁止凭单条绝对值下"爆款"结论。
