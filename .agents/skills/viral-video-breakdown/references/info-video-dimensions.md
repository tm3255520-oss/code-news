# 图文资讯视频专属拆解维度（Info-Video Dimensions）

适用形态：**白底幻灯片 + TTS 配音**的资讯/科普视频（如 DSH 赛道「小胖有事说」类）。现成爆款技能都是口播向，此文件补六个现成框架没有的维度，用于 L3 机制层。

> 判定是否本形态：画面≈静态图文（视频码率低、每页停留 3-7s）、旁白=TTS（逐字等于画面文字）、无真人。

## 维度 1：选题时效性与信息增量（信息型爆款的命门）

- 这条为什么"现在"值得发？抢的信息差是什么（新版本/新协定/社区事件/大地震）？
- 同题内容当前多不多？它比已有内容多给了什么增量（细节/规范名/仓库名）？
- 判断：`首发信息差 / 跟进解读 / 炒冷饭`。资讯视频的价值 = 信息增量 × 时效。

## 维度 2：图文TTS形态特征

- 幻灯片节奏：平均每页停留秒数、一句话一屏是否成立、画面文字密度。
- 画面动态：是否低动态（可用视频码率佐证，<300kbps 多为静态图文+入场动画）。
- TTS 特征：语速（字/秒）、音色（男/女、播音腔）、是否有停顿/情绪。
- 意义：这决定"能不能低成本批量复刻"——形态越模板化，制作成本越低，但同质化风险越高。

## 维度 3：资料来源可溯（资讯号的信任根基）

- 信息来自哪个一手源：GitHub 仓库（作者名/仓库名）、spec 文档、团队、官方发布、社区讨论。
- 报告必须列出来源清单；不确定来源的信息标"待核实"。
- 符合编辑铁律：仅平台可查数据标「数据来源」；不编造来源。
- 意义：可溯源 = 资料型价值（用户会收藏当资料） = 信任。

## 维度 4：信任构建逻辑（不是人设信任，是中立专业感）

口播靠人设信任；资讯靠这几种，拆解时逐一核对用了几种：

- 权威背书：点名团队/维护者（如 dsh-TUI 团队、社区发起人）。
- 开放姿态：强调开放协定、人人可参与、欢迎建言。
- 反固化立场：主动说"规范不把自己定义成标准""谁更好就站谁"——制造中立可信。
- 边界诚实：承认"没有完全免费的适配层"——坦陈代价反而增信。
- 判断：`背书 / 开放 / 反固化 / 坦陈代价` 各用了几层？复刻时必须复刻这层逻辑，而非背书对象。

## 维度 5：生产可行性评估（复刻 gating）

- 这条我们用现有工具能不能 1 人复刻？成本与耗时？
- 素材可得性：仓库/spec/截图/官方图能不能拿到？
- 输出：`可直接复刻 / 需补素材 / 成本高不划算`。
- 意义：拆解报告的最终目的不是分析完就完，是判断"值不值得做、能不能做"。

## 维度 6：转化路径差异（资讯视频的 CTA）

- 口播视频 CTA = 关注/私信/评论；资讯视频 CTA = **资料型动作**：
  - 给具体名字：仓库名、spec 名、团队名、关键词（供观众搜索/收藏）。
  - 收藏理由：这条值得当资料存。
  - 关注理由：持续更新某赛道情报。
- 判断：转化设计是否清晰可执行？是否制造了收藏/搜索冲动？

## 资讯视频拆解结论模板（融入十维表）

在十维拆解表之外，另起一节「资讯专属六维」，逐维一行：

```markdown
【资讯专属六维】
- 选题信息增量：首发 / 跟进 / 冷饭（依据：…）
- 图文TTS形态：每页停留约 Xs，TTS 语速 Y 字/s（依据：…）
- 资料来源：仓库/规范/团队（清单…）
- 信任构建：背书/开放/反固化/坦陈代价 各用了几层
- 生产可行性：可直接复刻 / 需补素材 / 成本高（依据：…）
- 转化路径：资料型收藏 / 关键词搜索 / 关注（CTA 原文：…）
```
