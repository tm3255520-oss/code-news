# 内容拆解方法论：从标题反推选题公式

指标层回答「结果差多少」，内容拆解回答「为什么差」。
这是拆解报告里唯一**必须由人来做判断**的部分——脚本能统计，归纳要靠你。

---

## 一、三步法

### 1. 标题结构分析（可脚本化）

从 `posts.json` 里把所有 `title` 提出来，跑三项统计：

| 统计项 | 看什么 | 怎么判读 |
|---|---|---|
| 长度分布 | 均值、最小值、最大值、是否集中 | 集中 = 刻意设计；发散 = 跟着热点走 |
| 2-gram 高频词 | 出现 ≥3 次的词 | 高频词就是账号的「内容主题指纹」 |
| 标点/情绪符号 | `？` `！` `...` 的密度 | 疑问收尾 = 制造好奇缺口；感叹收尾 = 情绪代入 |

Python 最小实现：

```python
import json, re, collections
posts = json.load(open("workdir/posts.json", encoding="utf-8"))["posts"]
titles = [p["title"] for p in posts if p.get("title")]

# 长度分布
lens = [len(t) for t in titles]
print(f"n={len(lens)}  均值={sum(lens)/len(lens):.1f}  范围={min(lens)}-{max(lens)}")

# 2-gram 高频词（中文按字滑窗，英文/数字按 token）
words = collections.Counter()
for t in titles:
    s = re.sub(r"[^\u4e00-\u9fa5]", " ", t)          # 先切出中文段
    for seg in s.split():
        for i in range(len(seg) - 1):
            words[seg[i:i+2]] += 1
    for tok in re.findall(r"[A-Za-z0-9.]+", t):       # 英文/数字 token
        words[tok] += 1
print(words.most_common(20))
```

注意：`title` 为空时别跳过——小红书部分笔记标题即正文首行，
空标题本身就是「不做标题优化」的信号，要在报告里提一句。

### 2. 选题公式提炼（人做）

把高频标题抽象成**成分叠加**的形式，格式固定为：

```
成分A（锁定人群） + 成分B（给出锚点） + 成分C（制造缺口）
```

判据：这条公式必须能**反推出该账号 60% 以上的标题**。推不出就不是公式，是巧合。

### 3. 形态与受众匹配（人做）

| 检查项 | 为什么看 |
|---|---|
| 图文 / 视频占比 | 单一形态 = 生产流程标准化、受众明确；多形态 = 广撒网 |
| 受众是「精准」还是「广泛」 | 标题里的词指向具体需求 = 精准；指向话题 = 广泛 |
| 标题是「筛选器」还是「新闻台」 | 筛选器：看到标题的人会想「这说的是我吗」；新闻台：谁都会点，谁都不深聊 |

**筛选器型标题的互动密度天然高于新闻台型**——这是解释「千粉均赞差距」最常用的内容层原因。

## 二、三条纪律（违反就别写进报告）

1. **样本 <20 条不归纳公式**，只做描述性统计。30 条以下标注「初步观察」。
2. **选题公式是归纳，不是统计检验**。报告里必须标「推断」，不能和「接口实测」的数据混在一起。
3. **相关 ≠ 因果**。高互动密度与某类选题同时出现，只能写「同时出现」，
   不能写「因为用了这个选题所以密度高」。这一步的诚实度决定报告的可信度。

## 三、实战案例（EVI vs 卡兹克，2026-09-05 实测）

| | EVI是个研究员（新号） | 数字生命卡兹克（大号） |
|---|---|---|
| 样本 | 30 条 | 92 条 |
| 选题公式 | 粉丝数 + 变现金额 + 反直觉疑问 | AI 热点 + 情绪化反应 |
| 高频词 | 什么×9 / 报价×5 / 凭什么×4 / 到底×3 | 今天×9 / 终于×9 / 上线×8 / Claude×7 / 我靠×6 |
| 标题长度 | 均值 19.7 字，集中 14–25 | 均值 19.8 字，范围 10–29（发散） |
| 形态 | 图文 100% | 图文 89% + 视频 11% |
| 受众 | 想学账号变现的人（精准） | 泛 AI 关注者（广泛） |
| 千粉均赞 | **52.1** | **6.45** |

结论写法示范（注意措辞留余地）：

> EVI 的标题在结构上更像「变现受众的筛选器」，卡兹克的更接近「AI 新闻台」。
> 两者与互动密度的差距**同时出现**——但选题本身无法从数据里统计出来，
> 这一步的判断是归纳，不是检验。

## 四、落地：把拆解变成自己的东西

1. 抽出对标账号的公式后，**先验证**：用这个公式写 3 条标题，看是否像他的号
2. 再**改造**：换掉与你自己定位冲突的成分（例：不做变现内容，就把「金额」换成别的锚点）
3. 最后**固化成模板**：标题结构、封面版式、更新节奏三项固定不变，连续做 30 条
   ——可识别度是靠「重复」攒出来的，不是靠单条爆款
