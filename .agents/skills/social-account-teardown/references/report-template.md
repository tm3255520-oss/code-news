# 拆解报告模板

生成 HTML（light 主题：浅底深字）。章节顺序有讲究——**先证据后结论，先数据后建议**。

---

## 0. 顶部：一句话结论 + 数据来源声明

```
◆ 结论：<账号名> 的核心竞争力是 <X>，不是 <Y>。复刻优先级：<1> > <2> > <3>。
   数据：n=<样本量> 条，跨 <起止日期>，全部来自 <平台> 真实接口 / 页面可见信息。
```

**必附数据来源声明表**（这是报告可信度的地基）：

| 数据项 | 来源类型 | 说明 |
|---|---|---|
| 粉丝数 / 获赞数 | 页面可见 | 主页 innerText 解析 |
| 作品赞/评/分享/收藏 | 接口实测 | `statistics.*` |
| 播放量 | ❌ 不可得 | 图文作品接口不返回 |
| 内容主题归类 | 推断 | 基于已下载图片人工归纳 |

**来源类型只能是这三种**：`接口实测` / `页面可见` / `推断`。
任何第四种都不要写——写了就是脑补。

---

## 1. 已验证数据

账号基本信息表 + `metrics.js` 输出的完整指标块。直接贴数字，不加修饰。

## 2. 作品全表

按时间倒序，列：日期 / 标题（截断 40 字）/ 赞 / 评论 / 分享 / 收藏 / 媒体数 / 话题。
**给出全部样本，不要只展示 TOP5** —— 只看头部会让人误判账号真实水平。

## 3. 内容形态拆解

- 单条作品的组成（图文号：封面图 → N 张内容图 → 尾图，各自承担什么功能）
- 单张图片的版式模板（如果有可识别的固定模板）
- 内容来源归类（基于**实际下载并查看过的图片**，不是凭标题猜）

> ⚠️ 如果要做形态拆解，**必须真的把图下载下来看**。
> 靠标题和文案推断视觉形态，等于没拆。脚本：`imgs/` 目录。

## 4. 复刻流程

把"如何做一条这样的内容"拆成可执行的步骤清单。
每一步要能直接做，不要停留在"要有网感"这种层面。

## 5. 复刻前要准备的东西

工具 / 素材源 / 技能的具体清单。

## 6. 风险审查 · 必须先知道的事

**这是最容易缺、也最重要的一章。** 至少三条：
- 版权/合规风险（图片来源、字体、音乐）
- 平台规则风险（搬运判定、原创度要求、结算门槛）
- 天花板风险（这个模式真实能赚多少，反推所需流量）

内容要具体，带数字。例：
> 图文伙伴计划单价 **5–8 元/万次播放**（不是中视频的 30–50）。
> 月入 3000 纯靠流量分成需 **375–600 万月播放**。

## 7. 内容配比建议

基于 TOP 作品 + 形态统计，给出可执行的内容组合比例。
例：`爆款型 30% / 稳定型 50% / 实验型 20%`

## 8. 立即可做的 N 条选题

具体选题清单，每条带：标题 / 可用素材方向 / 推荐话题标签。

## 9. 30 天路线图

按周分，每周有明确交付物和验收标准。

## 10. 自我纠错 · 我做错了什么 / 你要怎么验证

**必写。这一章的缺失会让整份报告的可信度归零。**

至少回答四条：
1. 本报告哪些结论是实测、哪些是推断？
2. 样本量是否足以支撑给出的百分比结论？
3. 如果我是反对者，从哪个角度能把这个方案打穿？
4. 我上一版（如果有）哪里说错了，错在哪？

并给出**用户可自己动手的验证方法**（例："去创作者后台看你自己三条内容的分享率，
如果低于 10%，说明我的判读基准不适用你的赛道"）。

---

## 风格要求

- **Light 主题**：浅色背景 + 深色文字，不要用深色卡片
- 数字用等宽字体，关键指标加粗
- 每个结论旁边标注支撑数据的来源和样本量
- 图表优先用简单的 CSS 条形图，不引外部库
- 不用 emoji 装饰标题
- 中文用直角引号「」
