# 动效词表（封闭表，只能用这里列出的）

分镜里的 `motion` 字段**必须是本表内的动词 + 目标**，写成
`动词 目标 → 动词 目标` 的形式（`→` 分隔，按出现顺序执行）。

**写表外的词会被 `storyboard_to_cards.py` 直接判不合格、不出片。** 这不是返工，
而是把"渲染器听不懂"这件事挡在渲染之前。

## 动词

| 动词 | 效果 | 适用目标 |
|---|---|---|
| `TYPES` | 逐字打出（打字机） | 标题、副标题（会拆成逐字 span） |
| `FLOATS` | 淡入 + 上浮 26px | 全部 |
| `SLIDES` | 从左滑入 46px + 淡入 | 全部 |
| `RISES` | 从下升起 72px + 淡入（幅度更大） | 全部 |
| `SLAMS` | 放大回弹（1.26 → 1）+ 淡入 | 标题、大字 |
| `STAGGER` | 子项错开淡入（间隔 0.14s） | **卡片**（多块时才有错开感） |
| `CASCADE` | 子项从左侧错开滑入（间隔 0.12s） | **卡片** |
| `FADES` | 纯淡入 | 全部 |
| `DRAWS` | 标题下划线从左画出 | 标题（会自动加一条荧光绿线） |

## 目标

| 目标 | 对应画面元素 |
|---|---|
| `标题` | 卡片大标题 |
| `副标题` | 标题下的说明行 |
| `标签` | 左上角的小标签（kicker） |
| `卡片` | 内容块（多个块会按 STAGGER/CASCADE 错开） |
| `大字` | 大字对比行（"3 小时 → 5 分钟"这类） |

目标**留空**表示作用于整张卡片的直接子元素（一般不这么写）。

## 节奏

多个动效之间**固定间隔 0.32 秒**依次触发。所以：

- 想"说完一句再出下一个" → **把动作拆成多条**，别写在一个动词里
- 一条 `motion` 写 3 个动作 ≈ 1 秒内完成
- 卡片本身有**相机缓慢推进**（全片统一，分镜不用写）

## 转场

`transition_in` / `transition_out` 只接受这几种，**"硬切"也必须明写**：

| 值 | 含义 |
|---|---|
| `硬切` | 无过渡（默认，最常用） |
| `FADES` | 淡入 / 淡出 |
| `FADES 到黑` | 淡到全黑 —— **只有末镜可用** |

末镜写 `FADES 到黑` 时，渲染器会自动加一层黑幕并淡入。

## 正确 / 错误示例

```
✅ TYPES 标题 → FLOATS 卡片
✅ SLAMS 标题 → FLOATS 卡片
✅ STAGGER 卡片 → FLOATS 副标题
✅ DRAWS 标题 → FLOATS 卡片

❌ TYPES 大标题            ← 目标名错误（应为「标题」）
❌ FLOATS 下一步卡片        ← 目标名是描述性中文，不是表内的「卡片」
❌ 卡片在 400ms 内浮入      ← 写了参数与自然语言，不是动词+目标
❌ STAGGER 三项检查逐项亮起  ← 同上
```

> 常见错误：用**描述性中文**当目标（"规格卡片""标题下划线""三项检查逐项亮起"）。
> 分镜读起来通顺不代表渲染器能执行——目标名必须是上表里的那 5 个之一。
