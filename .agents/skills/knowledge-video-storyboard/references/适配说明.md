# 上游规范 → 本产线的替换规则

`references/` 下三份文件**逐字保留上游原文**（见 `upstream/PROVENANCE.md`）。
但它们是为上游的「交互访谈 + 8 套预设主题 + markdown 交付」写的。
本文件是**唯一的替换口径**——读原文时遇到下列概念，按本表落地。

---

## 一、四个必须替换的概念

| 上游原文说 | 本产线替换为 |
|---|---|
| **组件 ID**（来自 `components-catalog.md`，不许自创） | 我们的卡片内容块：`screen.blocks[].label` 是**自由文本标签**（如 `INPUT` / `规则` / `CTA`）。因为没有组件库，**这条"不许自创"约束对我们不适用**，改为约束见下 |
| **视觉主题**（Swiss Pulse 等 8 预设 / `design.md`） | 我们的卡片模板 `video-line/`（暗色网格 + 荧光绿，4:3 1440×1080）。**不接受在分镜阶段指定主题** |
| **预估时长**（`pacing-rules.md` 的节奏基准） | **TTS 实测时长**。节奏基准只用来**校验信息密度**，不用来定时长 |
| **9 节 markdown 交付件**（`video-spec-template.md`） | `storyboard.json`（结构见 `SKILL.md`） |

> ⚠️ 原文中所有 `components-catalog.md` 的引用在本技能内**不成立**（该文件刻意未引入）。

## 二、字段映射（上游 §6 分镜表 12 字段 → 我们）

| 上游字段 | 落到我们哪 | 是否驱动渲染 |
|---|---|---|
| 类型（A-roll / B-roll / 转场） | `scenes[].type` | 否（供筛选/自检） |
| 组件 | `screen.blocks[].label` 自由标签 | 是 |
| 旁白文案 | `narration`，且必须**逐字等于** `lines[from-1..to-1]` 的拼接 | 是（决定时长） |
| 屏显文案 | `screen.title / kicker / subtitle / blocks / big` | 是 |
| 期待内容 | `content_expect` | 否（自检用） |
| 期待效果 | `effect_expect` | 否（自检用） |
| 画面描述 | `visual` | 否（本轮仅文档） |
| 动效要点 | `motion`，按 `references/动效词表.md` 的封闭词表翻译成 GSAP | **是** |
| 音效描述 | `sfx` | 否 |
| 转场进入 / 离开 | `transition_in` / `transition_out`（硬切 / FADES / FADES 到黑） | **是** |
| 素材依赖 | `assets` | 否 |

## 三、时间：我们比上游更准，用我们的

上游要求「叙事节拍各段时间区间加起来 = 全片总时长」，允许 ±0.5s。
我们**不需要预估**：旁白先做 TTS，用 `voice_timeline.json` 的实测时长回填每一镜的
`start` / `duration`，所以这条约束天然满足且**零误差**。

**所以分镜表里禁止写时长。** 只写 `from`/`to`（口播稿行号），时长由管线回填。

## 四、保留的上游硬校验（这些我们照做）

从 `spec-rules.md` §6 挑出适配我们的部分：

1. **每个镜头必须有明确的信息载荷**——`content_expect` 不接受"讲一下背景"这类空话
2. **期待效果不接受"好看/高级"**——必须写观众会产生什么反应
3. **动效要点只写动词**（SLAMS / FLOATS / DRAWS / TYPES），不写 ms 与缓动参数
4. **旁白文案与屏显文案必须分开写**——一个是听到的，一个是看到的
5. **hook 镜头必须落在开头 3 秒内至少 1 个**
6. **过场镜头占比 ≤ 15%**
7. **不允许空帧**——每个镜头都要有信息载荷
8. **核心信息 ≤ 12 字**

## 五、动效已接通（2026-09-16 扩展后）

`motion` / `transition_in` / `transition_out` **已经驱动渲染**：
`build_card_deck.py` 内置封闭动词表，按 `references/动效词表.md` 把
`动词 目标 → 动词 目标` 翻译成 GSAP 时间线，各动作间隔 0.32s。

动词与目标**必须来自词表**——不在表内的词由 `storyboard_to_cards.py` 直接判不合格。
这样"渲染器听不懂的动效"不会走到渲染阶段。

**仍未接通**（如实记录）：

- `visual`（画面描述）——模板版面由卡片结构决定，不接受自由画面描述，仅作文档
- `sfx`（音效）——仅作文档，暂不放音效
