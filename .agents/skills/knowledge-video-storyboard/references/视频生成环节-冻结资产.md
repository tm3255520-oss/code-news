## 一、这一段在产线里的位置

```
storyboard.json ──③ storyboard_to_cards.py ──► script.json（+ 校验报告）
                   （硬校验：不过不出片）
script.json ──────④ build_card_video.py ─────┬─ voice_segmenter.py（edge-tts 逐段配音）
                                             ├─ 按语音实测时长分组 → cards.json
                                             ├─ build_card_deck.py → video-line/index.html
                                             └─ hyperframes render → final.mp4
                 ──⑤ hyperframes check ─────► 质量门（lint / runtime / layout / contrast）
```

**契约一句话**：判断（题材、节拍、画面意图）全部发生在这一段**之前**；
这一段只接受 `script.json` 里写死的事实，不做任何创作判断。

## 二、不可变项（要动先问：是不是必须动）

| # | 钉住的东西 | 值 / 位置 | 为什么不能随手改 |
|---|---|---|---|
| 1 | **配音先行** | 卡片时长、字幕轴全部由 TTS 实测时长推出 | 写死页时长会与语音脱节；这一条是整段的根基 |
| 2 | **画布与色彩** | 画幅由 `--format` 选：`landscape` = 1440×1080（4:3，默认、归档画幅）／`vertical` = 1080×1920（9:16，视频号·抖音·小红书投放）；30fps、H.264 + AAC 48kHz 立体声；米色外框 + 深色网格面板 + 荧光绿强调 | 切画幅**只许改版式**：元素、动效目标、时间轴必须逐项一致（回归门 `test_switching_format_changes_layout_only` 守着）。横屏输出是冻结基准，改动必须只剩已知的两行 |
| 3 | **封闭动效词表** | `references/动效词表.md`（9 动词 × 5 目标） | 分镜只能写表内词；表外词在 ③ 直接被判不合格 |
| 3b | **动效目标必须与画面内容对得上** | 目标 ↔ 必需字段：标题→`screen.title`、副标题→`screen.subtitle`、标签→`screen.kicker`、卡片→`screen.blocks`、大字→`screen.big` | 写了「FLOATS 卡片」但那一镜只有单元 → 渲染器找不到目标、**静默失效**（2026-09-16 补校验） |
| 4 | **信息单元四件套** | `list` / `stat` / `compare` / `steps` | 每个单元都内化了配方卡的参数边界与已知坑 |
| 5 | **质量门** | `hyperframes check`，不过门返回非零码 | 抓到过 content_overlap、GSAP 目标失效、stat 压叠三类真缺陷 |
| 6 | **预览确认点** | `--preview N` 只渲前 N 秒 | 在样片上改一次是重渲几十秒，整片渲完再改是全部重来 |
| 7 | **单卡时长来源** | 卡片之间不留空洞，末卡收在音频末尾 | 否则会出现画面停住、语音还在走 |

**生成物不能手改**：`video-line/index.html` 是 `build_card_deck.py` 的**产物**，每次运行都会被覆盖。
要改版面就改生成器（`build_card_deck.py`），不要改 `index.html`。
（`video-line/` 里的 `meta.json` / `hyperframes.json` / `compositions/` 是项目定义，不算产物。）

## 三、输入输出契约

**输入**

| 文件 | 谁产出 | 关键字段 |
|---|---|---|
| `storyboard.json` | 本技能（LLM 判断） | `video` / `lines` / `beats` / `scenes[].screen.units` / `motion` / `transition_*` |
| `script.json` | `storyboard_to_cards.py` | `lines` + `cards[]`（`from` / `to` 是**口播行号**，不是秒） |

**输出（默认写在 `--out` 目录）**

| 产物 | 说明 |
|---|---|
| `voice/voice_segmented.mp3` / `.srt` / `voice_timeline.json` | TTS 原件；`voice/_segments/` 下是分段与裁静音的中间件 |
| `cards.json` | 分组后的卡片 + 字幕时间轴（渲染的真正输入） |
| `video-line/index.html` | 生成的合成（会被下次运行覆盖） |
| `final.mp4` / `preview.mp4` | 成片 / 样片 |
| `storyboard.check.md` | ③ 的校验报告（人读） |

**默认参数**（改之前先看实测依据）

| 参数 | 默认 | 依据 |
|---|---|---|
| `--rate` | `+28%` | 实测 6.07 字/秒，对齐对标片 C 基线 6.03 字/秒 |
| `--gap` | `0.16` | 最终停顿 ≈ 0.06（段尾保留）+ 0.16 ≈ 0.22s |
| `--quality` | `looks` | 草稿用 `draft`，交付用 `delivery` |
| `--voice` | `yunjian` | 音色自然度**无法由脚本判定，必须人工听一次** |
| `--format` | `landscape` | `vertical` 出竖屏（1080×1920）。**配音先行不受影响**：同一份 script.json 与同一条音轨，换的只是版式 |

## 七、改动纪律

改任何一项都要**顺着链路同步**，否则会出现「分镜写得对、渲染器不认」的静默失效：

| 要加什么 | 必须同时改 |
|---|---|
| 新动效动词 | `build_card_deck.py` 的 `VERBS` + 本技能 `references/动效词表.md`（`storyboard_to_cards.py` 直接 import `VERBS`，白名单自动同步） |
| 新信息单元 | `build_card_deck.py` 的 `UNITS` + `render_card()` 渲染 DOM + `build()` 挂 GSAP + `storyboard_to_cards.py` 的项数校验 + SKILL.md 单元表 |
| 模板版面 / 配色 / 字号 | 只改 `build_card_deck.py`；改完**必须重渲 + 抽帧核对 + 跑质量门**（`index.html` 是产物，会被覆盖） |
| 新增目标名（选择器） | `build_card_deck.py` 的 `TARGET_SEL` + 动效词表的目标表 |

**验收判据（改完必须全过）**：① `storyboard_to_cards.py` 报 0 错误；② 质量门 `Check passed`
且 Contrast 有实际条目数（不是 0/0）；③ 逐帧抽图目视核对；④ 密度用同一把尺子量（对标 C 2.66%）。
