# 抽帧目视复核

脚本给不出"画面长什么样"，这一步补齐。

## 抽两类帧

**1. contact sheet（总览，先看这张）**

```bash
# 每 3 秒一帧，缩到 150px 宽，排 6x3 网格
ffmpeg -v error -y -i video.mp4 -vf "fps=1/3,scale=150:-1" frames/f_%03d.jpg
ffmpeg -v error -y -i frames/f_%03d.jpg -vf "scale=150:-1,tile=6x3" -frames:v 1 contact_sheet.jpg
```

一张图看完整个视频的视觉走向，最省 token。

**2. 全分辨率单帧（读细节）**

在下列位置各抽一帧原图：

- `0s` — 黄金 3 秒怎么开的
- 每个切点前 0.5s — 转场前画面
- 有字幕的最长一帧 — 读字幕样式（字号/行数/高亮规则）
- 有数字或图表的一帧 — 读信息呈现方式

```bash
ffmpeg -v error -y -ss <秒> -i video.mp4 -frames:v 1 -q:v 2 out_<秒>.jpg
```

## 目视要确认的 5 件事

1. **动效形态**：卡片滑入 / 淡入 / 打字机 / 图表生长 / 实拍？
2. **字体层级**：大标题字号、颜色、是否有渐变填充
3. **字幕**：位置（底部居中？）、行数、是否关键词高亮、是否有半透明底条
4. **画面三区**：内容区 / 字幕条 / 页脚（品牌徽章、水印）分别占多少高度
5. **静态还是动态**：同一镜头内画面有没有变化（配合 `static_shot_ratio` 交叉验证）

## 抽帧后必须做的交叉验证

把目视结果和 A 组的 bpp 对比：

- bpp 低 + 目视是设计过的图形卡片 → 确认为图文动效片
- bpp 低 + 目视是实拍 → 说明是高压缩实拍，形态判定要改口
