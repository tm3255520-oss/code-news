# 爆款拆解报告：B1 补充 7 条（紧凑版）

> 用于把校准集从 8 条扩到 15 条。每条含：数据门结论 + 机制简析 + 是否值得复刻。

## 1. Git源宝《【网络热门AI鉴定】全网刷屏的DeepSeek多模态实测到底行不行？》3:45
- **数据**：5.7万播放 / 收藏率4.4% / **投币率3.6%** / 评论54｜数据门 ✅
- **机制**：**热点验证型评测**——"全网刷屏的多模态到底行不行"，用实测回答热议问题，投币率极高说明"真金白银认可"。评测类内容有信息增量+结论明确。
- **值得复刻**：值得。选题=抢热点+给结论；这类"鉴定/实测"骨架对 DSH 新功能极其适用。

## 2. ChHsich《DSH 开源一周，最火的 5 个插件项目》5:06
- **数据**：2.9万播放 / 收藏率3.5% / 投币率0.2%｜数据门 ⚠️
- **机制**：**清单类**——"最火 N 个插件"，信息聚合价值（收藏率高），但无个人实测/观点（投币率低），属"汇总搬运"。
- **值得复刻**：条件可复刻——清单骨架 + 至少对 1-2 个做实测点评，把"汇总"升级为"筛选+验证"。

## 3. 塔斯海《做了个插件，把AI对话侧边栏变成视觉地图》4:53
- **数据**：8.6k播放 / 收藏率5.2% / 投币率0.5%｜数据门 ❌（相对月匠同类型 107k）
- **机制**：**插件作者自推**（同月匠类型），但**新插件首次展示 vs 月匠版本更新回流**——月匠有既有用户基础，塔斯海无。
- **值得复刻**：控制变量启示——**插件作者要积累用户后再靠"更新即内容"起量**；新插件首发单独很难爆。

## 4. -Xiao_Mai-《如何安装DeepSeek Harness并简单使用》5:41
- **数据**：2.4k播放 / 收藏率2.7% / 投币率1.4%｜数据门 ❌
- **机制**：**纯安装教程**，无差异化定位、无热点、无个人观点，开场是噪声（音乐）——信息增量低，撞车大量同类教程。
- **值得复刻**：不值得单独做；要做教程必须加"差异化角度"（见源宝的"全体系"定位）。

## 5. 林粒粒呀《【小白8分钟速通】DeepSeek Harness 安装使用教程》7:53
- **数据**：9.6k播放 / 收藏率6.7% / 投币率1.5%｜数据门 ⚠️
- **机制**：**小白速通教程**+个人讲解，收藏率高（资料价值），但播放中量——垂类教程的下限表现。
- **值得复刻**：可复刻——"小白+速通+收藏导向"是教程类的安全打法，天花板取决于选题热度与账号基础。

## 6. 把爱留在618《DeepSeek Harness实测：AI渗透测试自己挖洞》6:49
- **数据**：7k播放 / 收藏率4.7% / 投币率0.4%｜数据门 ⚠️
- **机制**：**实用演示**——"用 DSH 做渗透测试"，具体场景+演示，收藏率不错，但投币率低（娱乐/工具向，非"必须看"）。
- **值得复刻**：条件可复刻——"DSH 应用于具体场景"的演示类，适合做系列（DSH 做渗透/做爬虫/做办公）。

## 7. 哎呦哎呦李《DeepSeek Harness中文插件》0:59
- **数据**：2.9k播放 / 收藏率3.7% / 投币率0.3%｜数据门 ❌
- **机制**：**超短体验分享**（59s），个人粉向安利，无结构无干货。
- **值得复刻**：不值得——超短视频若无可收藏/可行动内容，留存与价值都弱。
