# 精确作者中位数：宿主机执行方案（A3）

## 为什么需要宿主机

- B站 **空间 API**（`x/space/arc/search`）返回作者全部视频的播放量，是精确中位数的唯一来源。
- 沙箱 IP 被 B站 风控（412 / -352），且空间接口通常要求登录 cookie；**沙箱内只能拿到"搜索采样近似中位数"**（偏高偏保守，`author_medians.json` 当前即此）。
- 你的宿主机 B站 已登录、IP 干净 → 空间 API 可用 → 可拿**精确**中位数。

## 怎么做

1. 在宿主机**双击** `run_precise_median.bat`（位于本目录）。
   - 等价命令：
     ```
     cd C:\Users\Administrator\Documents\code-news\.agents\skills\viral-video-breakdown
     python scripts\collect_bili_candidates.py --config config.yaml --out-dir C:\Users\Administrator\Documents\code-news\research\dsh-std-video-analysis\candidate_pool
     ```
2. 采集器内置逻辑：空间 API 成功 → `author_median` 记为**精确**（日志 `[作者] ...(space)`）；空间 API 失败 → 自动降级为搜索近似（日志 `(search-approx)`）。
3. 运行后检查输出 `candidate_pool_*.md` 的"相对作者中位数"列：若来源是 space，即为精确值。

## 验收标准

- [ ] 宿主机运行后，`candidate_pool_*.md` 中至少头部作者的中位数来自 `(space)`（日志可见）。
- [ ] 用精确中位数回填 `author_medians.json`（把"近似中位数"替换为精确值，`方法` 字段改为 "space 空间 API"）。
- [ ] 校准结论 `Phase2校准结论.md` 中的相对倍数随之更新（如鱼皮精确中位数可能 ≠ 318,380）。

## 备注

- 宿主机若无 Python，需先装 Python 3.10+（采集器只用标准库，无第三方依赖）。
- 若宿主机空间 API 也返回 -352，则需走 BSK 带登录态执行（届时再议）。
