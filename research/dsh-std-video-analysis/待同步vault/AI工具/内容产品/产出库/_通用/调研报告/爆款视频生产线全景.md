# 爆款视频生产线（全景梳理）

> 更新：2026-08-26｜定位：从"数据选样"到"出片+回测"的 DSH 爆款视频全自动/半自动流水线
> 原则：**数据驱动选样、机制级拆解、学机制不抄表达、复用 Hermes 现成工具链、不重复造轮子**

---

## 一、生产线总览

```
┌─────────┐   ┌─────────┐   ┌─────────┐   ┌─────────┐   ┌─────────┐   ┌─────────┐
│ 候选池   │ → │ 爆款拆解 │ → │ 复刻     │ → │ 视频生产 │ → │ 发布     │ → │ 回测闭环 │
│ 采集+评审 │   │ 证据+机制 │   │ 脚本/分镜 │   │ 配音+合成 │   │ B站首发   │   │ 数据回填  │
└─────────┘   └─────────┘   └─────────┘   └─────────┘   └─────────┘   └─────────┘
   每10分钟      按需         按需         宿主机       人工          每天
   (定时)      (Claude)     (Claude)     (双击.bat)   (审核发布)     (自动)
```

**执行分工**：Claude 沙箱负责"选样→拆解→复刻"的智能部分；宿主机（Hermes 工具链）负责"配音+合成"的确定性生产；发布由人工审核；数据回填自动。

## 二、主要功能模块

### 模块 A｜候选池采集（数据驱动选样）
- **目的**：摆脱人工/员工主观选样，用 B站 公开数据自动发现 DSH 爆款候选。
- **关键能力**：关键词搜索（免登录）、单视频全指标（播放/点赞/评论/收藏/投币/分享/弹幕）、作者空间枚举（精确中位数）、质量代理指标（收藏率/投币率，替代拿不到的完播率）。
- **入口**：`collect_bili_candidates.py`，每日 09:34 定时任务 `dsh-candidate-pool-daily` 自动跑。
- **产出**：`candidate_pool/candidates_*.json|csv` + 人读清单。

### 模块 B｜爆款拆解（证据驱动）
- **目的**：把候选视频拆成"为什么会火 + 结构骨架 + 可复刻机制 + 是否值得复刻"。
- **五层**：证据提取(下载/OCR/转写) → 结构还原(分段/钩子/标题公式) → 机制判断(人群/情绪/信任/转化) → 数据门(防伪爆款) → 产出报告。
- **关键工具**：`extract_video_evidence.py`（头条+B站 证据包）、`correct_transcript.py`（LLM 校稿+术语兜底）、`run_breakdown.py`（一键编排，NVIDIA 可用自动出报告，否则出素材包）。
- **产出**：`爆款拆解报告.md`（含爆款DNA、底层公式、复刻边界）。

### 模块 C｜复刻（脚本生成）
- **目的**：消费拆解报告的"爆款DNA+底层公式+复刻边界"，产出可进生产线的复刻包。
- **输出**：新选题定位、标题候选、封面文案、前3秒钩子、完整旁白稿、分镜、素材清单、剪辑提示、评论/收藏触发、发布前检查。
- **铁律**：学机制不抄表达；复刻边界自检（标题/旁白/画面差异化）。
- **入口**：`viral-video-replicate` skill + `references/replicate-output-template.md`。

### 模块 D｜视频生产（配音+合成）
- **目的**：把复刻包变成可发布的 720p 视频。
- **配音**：复用 Hermes `voice_segmenter.py`（edge-tts 已装 7.2.7；逐段 TTS+停顿+SRT；音色 yunjian/xiaoxiao 等；可切 Fish Audio 付费音质）。
- **合成**：幻灯片生成（PIL 白底大字）+ ffmpeg 拼接（沙箱演示版 `make_slideshow_video.py`；生产可对接 Hermes `video_enhance/` 管线）。
- **执行**：宿主机（沙箱网络受限，TTS/长视频下载只能在宿主机）。

### 模块 E｜发布与回测（闭环）
- **发布**：人工审核后 B站 首发（C3 执行单），头条二次分发。发布能力默认关闭，绝不自动发布。
- **回测**：`track_predictions.py` 刷新真实数据，对比"拆解预测 vs 实际"，基线准确率 100%。
- **趋势**：`trend_report.py` 用积累快照出 DSH 热度/作者增长周报。

### 模块 F｜知识沉淀（vault 同步）
- **目的**：让所有产出自动进 Obsidian（Claude 沙箱对 vault 只读，架构限制）。
- **机制**：Claude 产出 → 放 `待同步vault/`（按 vault 相对路径）→ Hermes cron 每 10 分钟 `sync_to_vault.py` 自动同步。
- **状态**：已上线并运行。

## 四、操作流程（端到端）

### 流程 1：每日例行（自动）
```
09:34  定时任务采集候选池 → candidate_pool/
随时   Hermes cron 每10分钟把待同步vault/ 同步进 Obsidian
每天   （可选）跑 review_candidates.py 得今日拆解队列
```

### 流程 2：选样拆解（Claude 按需）
```
1. review_candidates.py → 挑 Top5 候选
2. run_breakdown.py <url> → 证据包 + 拆解报告（含数据门判断）
3. 数据门 ❌ → 不进入复刻；✅/⚠️ → 可进入复刻候选
```

### 流程 3：复刻（Claude 按需）
```
1. 读拆解报告（爆款DNA/底层公式/复刻边界）
2. viral-video-replicate → 复刻包（标题/封面/钩子/旁白/分镜/素材）
3. 复刻边界自检（差异化）
```

### 流程 4：生产（宿主机）
```
1. 准备 口播JSON（从复刻包旁白稿转）
2. 宿主机 voice_segmenter.py → 逐段配音 mp3
3. 幻灯片 PNG + ffmpeg → 合成 720p 视频
4. （可选）对接 Hermes video_enhance 管线做增强
```

### 流程 5：发布与回测（人工 + 自动）
```
1. 人工核实事实 → B站 首发 + 头条二次分发
2. 记录数据回填 predictions.csv
3. track_predictions.py → 更新准确率
```

## 六、技术栈与复用原则

- **Claude 侧**：Python 标准库 + urllib + PIL + ffmpeg + tesseract + faster-whisper；LLM 校稿/拆解判断用 NVIDIA NIM（minimax-m3）。
- **Hermes 侧（复用）**：edge-tts（配音）、video_enhance 管线（生产）、Whisper large-v3-turbo（转录）、cron 系统。
- **铁律**：确定性流程禁用 LLM（🔵≥80%）；失败直接跳过；不绕过平台限制；发布默认关闭；**开发前先查 `.hermes/skills` 与 `.hermes/scripts` 现有工具，不重复造轮子**。
