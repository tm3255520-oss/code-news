## 待完善项（跑通过程发现）

1. **Git 提交在沙箱不稳定**：`.git/index.lock` 反复被宿主机 git 自动提交进程（git_autocommit）抢锁，沙箱侧 commit 多次失败。→ 待处理：协调 git_autocommit 与沙箱写入（或沙箱用独立分支/延迟提交）。
2. **voice_segmenter 默认 engine 是 fish**（付费），.bat 里已显式 `--engine edge` 指定免费。→ 提醒：勿删该参数。
3. **edge-tts 已装**（Hermes venv 7.2.7），无需安装——已移除多余的 install-edge-tts.bat。
4. **沙箱不能跑宿主机 venv python / 不能下载长视频 / 不能调 edge-tts**（网络+架构），生产环节必须在宿主机。
5. **口播/幻灯片需要人工核对**：DSH 插件市场是否真实上线未核实（发布前必须核实，C3 执行单已有）。
6. **视频号发布**：Hermes multi-platform-publish 有视频号链路（channels.weixin.qq.com 自动化，2026-08-15 跑通），需宿主机 BSK/登录态，发布动作人工确认。
