## 快速上手

**安装**：

```bash
uv pip install everos
# or: pip install everos
```

**启动演示**：

```bash
# If you installed EverOS as a package:
everos demo

# If you cloned or forked this repository and have not activated .venv:
uv run everos demo
```

**初始化**：

```bash
everos init
```
