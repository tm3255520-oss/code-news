## 6. 登记边界决策（2026-09-27）

**决策：15 条基础设施 cron 维持不入 `tool_registry.json`。**

理由：

1. registry 是「能力路由」，消费方 `scripts/tool_inventory.py` 与 `scripts/run_v3_content_ops.py` 都按 `interfaces` 取「能力」，不是按「任务」取。
2. 日志轮转、健康巡检、vault 同步、git 留痕、模型配置汇总等，不是可被 Agent 路由的能力；登记进去会稀释 registry 的语义。
3. 这类任务已有自己的追踪源：调度真相在 `.hermes/cron/jobs.json`，健康由 `cron_watchdog` + `hermes-doctor` 覆盖，日志由 Log Index / Log Watchdog 覆盖。
4. 纳入标准参照：registry 已收录 `proxy_health_check`、`browser_extension_inventory`、`tool_inventory` 等，说明标准是「能力」而非「定时任务」，基础设施任务不满足。

该决策已写入 `config/tool_registry.json` 顶层 `scope` 字段，随表生效，避免后续 Agent 重复误判。

### 7.3 两个必须记录的环境问题

1. **Windows 控制台编码（会导致崩溃，不是显示问题）**：官方 skill 的脚本直接 `print` emoji，但没有 `sys.stdout.reconfigure(encoding="utf-8")`。在 GBK 控制台下会抛 `UnicodeEncodeError` 直接崩溃（`douyin-daily-hot` 实测，且崩溃发生在**已经调用完 API 之后**——即钱花了、结果没出来）。运行时必须加 `PYTHONUTF8=1` / `PYTHONIOENCODING=utf-8`；接入产线时要在 wrapper 里兜住。我们的自研脚本都有这一行，官方 skill 没有。
2. **榜单数据口径是 T+1 / T+2**：抖音日榜 06:00 更新昨日、影响力榜 17:30 与 18:00 更新、小红书 19:00 后才更新。默认查「今天」会返回空。这与我们公众号榜单脚本的既有口径一致（end 必须是昨天）。

### 9.4 内容线断链的根因（2026-09-27 排查结论）

链路：`每日情报-1/2` → `daily_content_refiner` 候选池 → 公众号文章生成 → 小红书 / 知乎 / 贴图 / 视频号

**根因一：上游模型 job 断连（09-25 / 09-26）**

- `每日情报-1-Skills与MCP核心榜`、`每日情报-2-全球开发者趋势`（模型型 job，模型 `agnes-2.5-flash`）两天的输出头都标着 `(FAILED)`，错误是 `RuntimeError: Connection error.`
- 后果：AI 日报 01/02 未产出 → 提炼器拿不到 GitHub 项目 → 候选池 `TOP 0`（09-25、09-26 两次运行的「候选池构成」行都是 `新建仓库榜 0 个 + 周增榜 0 个 → TOP 0`）。
- 证据：`内容生产/情报与选题/AI日报/` 下 09-20～09-24 每天都是 01/02/03 三个文件；**09-25、09-26 只有 03**；09-27 恢复为三个。
- 关键点：**写入看门狗当天就报了警**（`❌ cron 输出中未找到 Response 部分`，exit 1，已推飞书）——监控有效，缺的是**处置**。

**根因二：候选池耗尽（09-27 起）**

- 日报恢复后候选池有 16 个，但历史已写 21 个 → 逐个命中去重 → `🛑 候选池耗尽`，当日 0 篇。
- 这是**结构性**的：候选池 = 日报 TOP N（实际 16），已小于历史累积（21）。脚本自身给的处置是「扩大 `REPO_POOL_SIZE`（默认 30）或清理/归档历史放开去重」，但 16 < 30 说明**瓶颈在日报提供的条目数，不在 POOL_SIZE**，单纯调大参数无效。

**连带与独立**

- 连带：小红书直接读「公众号深度文终稿」，上游 0 篇 → 必然失败（连挂 17 次）；贴图 CT-01 契约、视频号数据快照同理。
- 独立：知乎线是 `合规检查未通过（1 Critical + 1 High）`——极限词「第一」+ 原创度 51%（要求 60%）。这是内容门禁在拦，与上游无关；连挂 16 次说明**门禁拦下后没有修正回路**。

> 本轮**只诊断、未改内容线**（用户口径为"排查"）。
